# IronWallet Assets

Centralized repository for IronWallet blockchain asset definitions and static application resources. It contains blockchain metadata, network configurations, and shared resources used across wallet clients and services. [web:2][web:16]

## Purpose

This repository serves as a shared source of truth for asset-related data required by the IronWallet ecosystem. It helps keep blockchain metadata and supporting resources consistent, versioned, and reusable across applications and delivery workflows.

## Structure

Based on the current repository layout, the main directories are: 

- `blockchains/` — blockchain and network-related asset definitions
- `resources/` — shared static resources and supporting files

## Workflow

- `staging` — integration and pre-release validation
- `main` — production-ready branch

## Usage

Use this repository as the canonical source for blockchain asset metadata and static resources in wallet applications, internal services, and CI/CD pipelines.
